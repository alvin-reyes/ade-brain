# Developer knowledge

- 2026-11-09: macOS `script -q /dev/null cmd` refuses a mkfifo as stdin ("tcgetattr/ioctl: Operation not supported on socket", exit 1); feed it a real pipe. `wait` on the `$!` of a background pipeline waits for the whole pipeline, so kill a never-closing writer before waiting. lib.sh's fallback `timeout` runs the command with `&`, which gives it /dev/null as stdin in a non-interactive shell: don't use it to test stdin handling.
- 2026-11-09: Lock races need staggered takers to show up: 4 bash takers that spin on a go-file then `sleep 0.00$((RANDOM % 10))` hit the old mkdir/rm stale-takeover race in 2-8 of 30 rounds; without the stagger it is rarely seen. Never source tests/helpers.sh from the zsh tool shell (BASH_SOURCE is unset, REPO becomes / and make_hub tars the whole disk); run a bash script instead. `git checkout <file>` is blocked here: show mutation reds in a tar copy of the worktree.
- 2026-11-09: a test that runs a fake `claude` must `unset CLAUDE_CONFIG_DIR HUB_CLAUDE_CONFIG_DIR` first. The agent's own shell exports `CLAUDE_CONFIG_DIR`, so a launch without the prefix inherits it, and a fake that writes `settings.json` there overwrites the developer's real Claude settings (it happened once in SP's mutation run). The fake in `tests/test_providers.sh` also refuses to write outside the test's temp dirs.
- 2026-11-09: bin/work's launcher runs through osascript; a stub must run it with plain `bash "$L"`, not `bash -l`, or the login profile resets PATH and the real `claude` runs.
- 2026-11-09: don't patch bin/ scripts with a shell heredoc whose delimiter is `PY`: bin/work embeds `<<'PY'` blocks, so the outer heredoc ends early. Put the patch script in a file.
- 2026-11-09: `bash tests/test_providers.sh <check> ...` runs single checks, which helps for red-first evidence.
- 2026-11-09: macOS `mktemp -d` with no template ignores `TMPDIR` (it uses the per-user `/var/folders/.../T`); only an explicit template (`mktemp -d "$TMPDIR/x.XXXXXX"`) lands in `TMPDIR`. So "TMPDIR is empty afterwards" proves nothing about make_hub's dirs: list them and check each is gone. Grep-based mutations need `grep -F` when the pattern has `$` (BRE treats it as an anchor and the mutation silently does not apply: check the diff).
- 2026-11-09: since W1, bin/work inside an ADE terminal calls `$ADE_HOOK_BIN open` instead of osascript, so a test of the real (non-dry) launch must not inherit the agent shell's ADE_* vars: make_hub now unsets ADE_HOOK_BIN/PORT/TOKEN, ADE_PTY_ID and AGENT_TERMINAL. `bash tests/test_ade_open.sh <check>` runs single W1 checks; the full suite takes over 3 minutes, so run it in the background.
- 2026-11-09: to test stdin handling under a GNU-style `timeout` (none is installed here; lib.sh falls back to a backgrounded run that hides stdin), put a fake `timeout` (`shift; exec "$@"`) first on PATH for that one run. Time a command fed by a never-closing pipe as `{ sleep 30 & echo $! > pid; wait; } | { t0=$SECONDS; cmd; echo "$? $((SECONDS-t0))" > res; } &`, poll for `res`, then kill the sleep by its pid (see C18 in tests/test_ade_open.sh).
