# Developer knowledge

- 2026-11-09: macOS `script -q /dev/null cmd` refuses a mkfifo as stdin ("tcgetattr/ioctl: Operation not supported on socket", exit 1); feed it a real pipe. `wait` on the `$!` of a background pipeline waits for the whole pipeline, so kill a never-closing writer before waiting. lib.sh's fallback `timeout` runs the command with `&`, which gives it /dev/null as stdin in a non-interactive shell: don't use it to test stdin handling.
- 2026-11-09: Lock races need staggered takers to show up: 4 bash takers that spin on a go-file then `sleep 0.00$((RANDOM % 10))` hit the old mkdir/rm stale-takeover race in 2-8 of 30 rounds; without the stagger it is rarely seen. Never source tests/helpers.sh from the zsh tool shell (BASH_SOURCE is unset, REPO becomes / and make_hub tars the whole disk); run a bash script instead. `git checkout <file>` is blocked here: show mutation reds in a tar copy of the worktree.
